## Extra content

One extra, Secret Codes, which lists the game's 161 secret players and 25
codes over the game's logo while the game waits. The lists come from the
program ROM (the same in rev 1.21 and 1.2A); you still enter the players
and codes yourself. The game has no hidden menu.

| Page (OSD Secret Codes) | What it lists |
|---|---|
| Secret Players 1-3 | 161 secret players: initials and birthday to enter, and who each one is |
| Tonight's Game | 13 joystick-and-button codes: big, huge, tiny and normal heads for players and goalies, Big Puck, Baby Size Players, Fat Heads, Dark Rink, Top Display Off |
| Face-off | 12 codes for the time before the first face-off: Throwing Off, Super Goalies, Tournament Mode, Computer Assistance Off, Unlimited Turbo, Turbo Checks Off, Speed Up, the four Better codes and Fast Turbo Recovery |

The core-wide extras every game gets, and the other games' extras:

## OSD

The main page, in order: Video Settings; Secret Codes (below); DIP
Switches (Attract Sound, Bill Validator, Cabinet, Coinage, Coinage Source,
Counters, Head Size, Service Credit, Test Switch, Tilt); Service Mode;
Pause when OSD is Open; Reset and Reset and close OSD. The DIP switches
start at MAME's settings (Powerup Test, not on the page, stays Off). With
Coinage Source at CMOS (the default) the game takes its coinage from its
own adjustments, not from the Coinage switch.

## Controls

Turbo, Shoot / Block, Pass / Steal; up to four players.

## Secret Codes

The game hides 161 secret players behind initials and a birthday, and has
codes entered with the joystick and buttons before a game. OSD "Secret
Codes" shows them over the game's logo, and the game waits while the list
is up:

- Secret Players 1-3: the secret players, with who each one is
- Tonight's Game: the codes for the "Tonight's Game" screen
- Face-off: the codes for the time before the first face-off

Set it back to Off to play on. The lists are the ones in the program ROM
(the same in both revisions); you enter the codes yourself.

The ROM holds no names: the game shows the player's photo and a surname
plate. The surnames here are those plates (every entry entered in MAME);
the first names come from the game's credits (Midway staff), Chris
Blaney's GameFAQs FAQ, and, for the NHL players, the birthdays the entries
carry. A few birthdays are the game's own and differ from the player's
(Bernie Nicholls, Pierre Turgeon). "Evil Haeger" is the FAQ's name for the
third Haeger entry. In the OSD list a name too long for its column shows
its first name as an initial.

### Codes

Each code is a series of joystick and button states, entered on your own
controls. Every state has to follow the last within about a quarter of a
second, so enter them briskly.

| Notation | Meaning |
|---|---|
| U D L R | the joystick up, down, left, right as seen on the screen (UL, UR, DL, DR: diagonals) |
| T S P | Turbo, Shoot, Pass |
| `D+S` | at once |
| `(P) U UR R` | hold P through the moves after it |

On the "Tonight's Game" screen (the head codes change your own player, or
your team's goalie):

| Code | Inputs |
|---|---|
| Big Heads | `U+P+T` |
| Huge Heads | `U+S+P U U+S+P U U+S+P U` |
| Tiny Heads | `T T U S S U` |
| Normal Heads | `D+S P` |
| Big Goalie Heads | `P P T S P` |
| Huge Goalie Heads | `(P) U UR R DR D DL L UL U UL L DL D DR R UR U` |
| Tiny Goalie Heads | `(S) U UL L DL D DR R UR U` |
| Normal Goalie Heads | `S T P` |
| Big Puck | `U U D D T` |
| Baby Size Players | `D DR R UR U (T) U UR R DR D` |
| Fat Heads (others) | `L UL U UR R UR U UL L DL D DR R` |
| Dark Rink | `P+T P P+T P S+P P S+P P S+P P P+T P` |
| Top Display Off | `L+T L L+T L L+T L L+S L L+S L L+P L L+P L L+P` |

After "Tonight's Game", before the first face-off's help windows show:

| Code | Inputs |
|---|---|
| Throwing Off | `D+T U+S` |
| Super Goalies | `D D D D D P` |
| Tournament Mode | `R+S+P+T` |
| Computer Assistance Off | `U UR R DR D DL L UL U UR R DR D DL L UL U` |
| Unlimited Turbo | `T S S U UR R DR D DL L UL U` |
| Turbo Checks Off | `L+T L L+T L L+T L DL D DR R R+T R R+T R` |
| Speed Up | `S+T S+T R S+T D` |
| Better Shooting | `S S S S S T S S S S P` |
| Better Passing | `P T P T P P P P P T` |
| Better Checking | `U+P+T P+T U+P+T P+T U+P+T P+T L+P+T P+T R+P+T P+T R+P+T P+T` |
| Better Puck Handling | `S+P S+P P P S S T T T` |
| Fast Turbo Recovery | `R R R R T L L T R` |

Speed Up, the Better codes and Fast Turbo Recovery give your own player
one of these at a time. Tournament Mode (no power-ups, secret players or
computer assistance) and Unlimited Turbo need human players on both teams.
With the operator's Tournament Mode on, the game takes no codes.

The game does not name its codes: the names follow (shortened) the ones
published for the arcade game. Where a published input differs from the program's
(Throwing Off, Super Goalies, Better Puck Handling), the list gives the
program's, which was checked. Turbo Checks Off is in the program but in no
published list; its name says what it does there (Turbo with Pass, away
from the puck, gives the plain move), not checked in play.

## Notes

"OCTOPUS MENU" in the ROM is only the operator menu's internal name; there
is no hidden menu to open.
