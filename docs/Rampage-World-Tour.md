# Rampage World Tour

MRA sets: rmpgwt (rev 1.3), with rev 1.1 in `_alternatives`.

## OSD

The main page, in order: Video Settings; DIP Switches (Bill Validator,
Coinage, Coinage Source, Counters, Powerup Test, Service Credit, Test
Switch, Tilt); Service Mode; Pause when OSD is Open; Reset and Reset and
close OSD. The DIP switches start at MAME's settings. With Coinage Source
at CMOS (the default) the game takes its coinage from its own adjustments,
not from the Coinage switch.

## Controls

Jump, Punch, Kick; up to three players.

## Notes

"OCTOPUS MENU" in the ROM is only the operator menu's internal name; the
game's secret and hidden levels are part of normal play, not a menu.
