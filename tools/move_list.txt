# move_list.txt - the special moves on the core's Move List window (MK3, UMK3)
#
# Taken from MAME's command.dat (Command List by Fabricio Coroquer, revised
# and distributed by AntoPISA, version 0.273: entries mk3/mk3r20, mk3r10/
# mk3p40, umk3), written in the core's notation:
#   U D F B (and DF DB UF UB) the joystick, F toward the opponent; HP LP BL
#   HK LK RN the buttons; A+B together; Hold X 2s: hold X two seconds, let
#   go; (air): also in the air; Air: in the air only; (tap): tap the button
#   fast; (2P): two-player games only
# The finishing moves are not here: tools/finishing_moves.py reads them out
# of the program ROMs. tools/move_list.py builds the window from both.
#
# [set Character] then one move a line: name, two or more spaces, input.
# A line '- Name  input' is one of Shang Tsung's morphs.
#
